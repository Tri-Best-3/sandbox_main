# 시연 체크리스트 (CAPE 커스텀 룰)

## 0) 사전 준비
- 룰 설치 확인
```bash
python3 /home/my/cape_rules_module/cape_rules_installer.py --check-dst
```

## 1) Sigma 시연 (Event ID 4688)
- 실행
```
vssadmin.exe delete shadows /all /quiet
```
- 기대 결과
  - Windows 보안 로그 4688에서 룰 매칭

## 2) YARA 시연
- 테스트 파일 내용 예시
```
This is a ransom note. Your files are encrypted. Bitcoin payment required.
```
- 기대 결과
  - YARA 룰 매칭 (2개 이상 키워드)

## 3) Suricata 시연
- HTTP로 `.exe` 다운로드 요청 발생
- 예시 URL
```
http://example.com/test.exe
```
- 기대 결과
  - Suricata 룰 매칭

## 참고
- Sigma는 CommandLine 로깅이 활성화되어 있어야 탐지됨
- Suricata는 HTTPS에서 URI가 보이지 않을 수 있음
